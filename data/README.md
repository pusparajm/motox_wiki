# Data directory

`motorcycles.json`, `pages.json` and `settings.json` are the **source of truth**.
Everything else in this folder is generated by:

```bash
npm run build:data
```

## Files

| File | Generated? | Purpose |
|------|------------|---------|
| `motorcycles.json` | No | Full catalogue data: basic info, general specs, service data, torque tables |
| `motorcycles-index.json` | Yes | Compact summaries for browse cards and sorting |
| `motorcycles/<id>.json` | Yes | One lazy-loaded file per bike detail page |
| `pages.json` | No | Wiki article source |
| `pages-index.json` | Yes | Compact wiki page list |
| `pages/<slug>.json` | Yes | One lazy-loaded file per wiki page |
| `search-index.json` | Yes | Pre-flattened client-side search index |
| `popular-summaries.json` | Yes | Cache for the configured featured models |
| `settings.json` | No | Site title, navigation, ads, search and featured-model config |

## Spec sections

Bikes use a flexible section model:

- `general_specs` — key-value fields (engine, power, torque, chassis, dimensions, weight, fuel)
- `service` — key-value fields (oil capacity/grade, chain, spark plug, fork oil/seal)
- `torque_specs` — table rows (`component`, `torque`, `notes`). Every bike has one; verified family tables are used where available, otherwise the page shows a clearly labelled single-value general fastener reference.
- Any additional `fields` or `table` section is rendered automatically
- `custom_sections` — free-form HTML blocks

The compact index extracts `engine`, `power`, `torque`, `weight`, `seat_height` and
`fuel_capacity` from `general_specs` so cards and search results do not need to
load each detail file.

## Accuracy

The catalogue was rebuilt from public manufacturer and model data. Service
figures are included only where a reliable value was available; models without
verified service data show a "being compiled" note instead of generic values.

Specifications vary by model year and market. Treat them as a reference and
confirm against the official owner's or workshop manual before maintenance.
