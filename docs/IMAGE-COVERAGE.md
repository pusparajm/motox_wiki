## Notes

- All new images are 800x533 or larger at source and render as 3:2 AVIF, WebP and JPEG variants at 400, 800 and 1200 px.
- Every 1200 px AVIF is under 160 KB.
- No public model page contains a source name, source credit, logo or "Photo:" line.
- Public HTML contains no BikeDekho, CarBike360, MotorcycleSpecs or Wikimedia text.
- The three images removed after the crop review are listed in the rejection table above.

## Recommended next phase

1. Re-run the same matcher against BikeDekho for the Indian-market brands (Hero, Bajaj, TVS, Royal Enfield, Honda India, Yamaha India, KTM India), where MotorcycleSpecs coverage is thin.
2. Manually review the 25 MCS-indexed brands with zero images; many failures are year/gallery mismatches rather than missing pages.
3. Obtain unwatermarked CarBike360 originals for the models that remain blocked.
4. Keep the manual visual gate: contact sheets catch brochure scans and detail crops that file dimensions alone cannot.
